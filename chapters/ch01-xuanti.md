# 第一讲：选题

## 核心思想
好选题是好文章的一半。选题三要件：**有问题意识、有创新可能、切合个人情况**；检验标准是能否用**一句话**说出你的核心命题。

## 本讲框架
- **problem → question → thesis（问题意识三步）**
  - 何时用：任何选题初期、开题前自检。
  - 怎么做：①发现现实中"不对劲"之处（problem，实践困惑或认知困惑）；②放进学术语境、与既有讨论对话，提炼成学术话题（question）；③给出自己的命题（thesis）并论证。缺第①步→写成教科书；缺第②步→写成时评/调研报告；缺第③步→写成"说明文"。
- **四种视角：法官 / 立法者 / 决策者 / 观察者**
  - 何时用：确定研究立场、避免视角混乱。
  - 怎么做：以同一题目（如刑讯逼供）检验——法官问"证据能否采用"，立法者问"法律应否一律禁止"，决策者问"如何既遏制又不妨碍侦查"，观察者问"为何屡禁不止"。作者须清楚自己采取哪种视角及其局限。
- **论文类型二分**：规范研究（应当怎样：解释论 / 立法论 / 学理）vs. 实证研究（事实怎样：描述 / 原因 / 功能）；另有"综合研究"（现象—概念—规范—问题—对策的"散点透视"，今已不代表主流）。理论研究 vs. 应用研究按"写给谁、解决什么"区分。
- **提炼问题三规则**：①一篇论文只讨论**一个**中心问题；②**大处着眼、小处入手**（"小题大做"）；③**清楚合理界定**问题（防视角偏差与概念混淆）。
- **"一句话命题"测试**：问自己"你想说什么？能用一句话概括吗？"通不过者多为介绍性、教科书式文章，不算论文。
- **创新三来源**：新问题（被冷落的对象、新视角）、新见解（推翻常识或整理零碎知识）、新材料/新方法。创新的参照系是**整个学术圈**（中国法研究多为国内学术圈），而非身边的人。
- **切合个人情况四考量**：知识结构、资料可得、研究时间、学术/职业规划（"伤其十指，不如断其一指"）。
- **选题三阶段**：提出问题 → 先期调研（"涉市需谨慎，市调应先行"：是否值得写？是否写得了？）→ 调整论题（限缩拆分 / 深入扩展 / 转移）。

## 关键概念
- **法律帝国的疆域**：以国家机关、尤其法院适用的规则为"CBD"，向外延伸至比较法、法史、ADR、民间法、软法乃至一切社会组织规则——凡涉及人类社会组织规则者皆可为法学研究对象。
- **学术文章 vs. 非学术文章**：区别在交流对象与目的——学术文章写给同行，用语专业、重论证根据、带引注。
- **综述 / 评论 / 论文**：综述以述为主不加己见；评论须"有所寄附"、以评为主；论文是有条理地论证作者观点的文章，"为观点而生，为观点而终"。
- **核心命题（"骨髓"）**：贯穿全文的中心论点（引刘南平语）；标题如《××研究》往往暴露其缺席。
- **小得有道理**：缩小范围须有实质理由——被限定部分须具特殊性（"行政判决理由的说明"可以，"行政判决公开合议庭不同意见"则否）。
- **假问题**：几十年碰不上一回、对社会无影响的冥想式问题。

## 思维模型
- 把**找题目当谈恋爱**，命题作文如"拉郎配"——自己找题本身就是训练。
- 把**选题当投资**：先有资本（知识储备），再做市场调查（文献）。
- 用**"不对劲"嗅探器**找题：①现象几乎无人注意；②常识见解与事实冲突；③问题久议不决（需新视角/材料）；④争论时自己觉得有理却说不清（背后藏理论分歧）。
- **对策问题转理论问题**：对策取决于决策者权衡，学者更宜分析现象条件、决策后果与规律（如：违宪审查机构与人大制度、党的领导是否相容，而非设计宪法法院组成）。

## 反模式
- **教科书式选题**（"论缔约过失""行政检查研究"）：概念、性质、分类、意义平铺直叙，无重点无结论——"划了一块地，却不知道要种什么"。
- **多中心标题**（"若干问题""问题、原因和对策""几点意见"）。
- **论证断裂的双中心**：论"建立环保法庭的必要性"却大写"环保法律的重要性"。
- **热点撒胡椒面**：什么热写什么，"几个问题""若干方面"都说一通。
- **大词堆砌**（"司法治理全球化：民主转型与宪政再造"）；硕博论文普遍偏大。
- **漫无目的的比较**：几点相同、几点不同、几点启示。
- **伪视角创新**（"博弈论视角下的听证制度构建"却答不出原视角的问题与新视角的增益）。
- **写完才发现别人早写过**——缺最基本的学术训练。
- **生搬硬套陌生理论**（法经济学、协商民主等）。

## 示例演练
**拆分（作者本人经历）**：刘燕文案后，作者建档"晨光初现的正当程序原则"，多年写不成——既想证明原则已在中国司法中出现（实证），又想为其正当性辩护（规范），"一篇文章两个主题"。后拆为两篇：《司法判决中的正当程序原则》（经验层面：法院如何通过个案推动原则发展）与《正当程序原则的正当性》（规范层面：无明文规定时适用原则的正当性）。

**限缩（法律硕士案例）**：《行政强制措施》→《行政调查过程中的强制措施》→《卖淫嫖娼案件中的调查取证》；改小后迅速聚焦实践问题，"文章就有了血肉"。

**换问题（《行政诉讼撤诉考》）**：抓住悖论——法律禁止调解，变相调解（撤诉）比例却高达57%；法官呼吁严格把关却自己动员撤诉。于是问"为什么撤诉大行其道？"（实证），而不是"法官应否动员撤诉？"（规范）。

## 要点
1. 动笔前先过"一句话命题"测试；说不出一句话，就还没有论文。
2. 题目先求"小而具体"，再问"小得有没有道理"。
3. 创新以整个学术圈为参照——先检索，避免"高水平的重复"。
4. 明确自己是法官、立法者、决策者还是观察者，规范与实证不要混写。
5. 有资料、有知识储备、时间够、合规划，才是"你的"好题目。
6. 论题调整是常态：大则拆、浅则追问、正面难答则转移视角。

## 关联
- **第二讲**：先期调研即文献检索；关键词选择会遮蔽已有讨论。
- **第四讲**：规范/实证的区分在论证类型（描述、属性、原因、功能、解释、建议）中展开。
- **第五讲**：标题应体现核心命题；导论须交代问题与意义。
